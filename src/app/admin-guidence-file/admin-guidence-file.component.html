How to Use This System

This guide explains the complete business flow of Alo Spices. Follow the modules in the recommended order. Each section explains what the module is used for, what Admin needs to create, and where the created information is used next.

02

Masters

Master data is created first and is used throughout the system.

Brand

Masters → Brand

What is it?

Brand identifies the company or brand under which products are sold.

Admin needs to create

  • Brand Name
  • Description
  • Status
Used in: Product Sales

Category

Masters → Category

What is it?

Category is used to group similar products.

Example

  • Whole Spices
  • Spice Powders
  • Masalas
Used in: Product Sales

Supplier

Masters → Supplier

What is it?

Supplier represents the person or company from whom raw materials are purchased.

Admin needs to create

  • Supplier Name
  • Mobile
  • Email
  • GST / PAN
  • Address
Used in: Stock Receive Raw Material Stock

Warehouse

Masters → Warehouse

What is it?

Warehouse is the physical location where raw materials and finished goods are stored and where production can happen.

Admin needs to create

  • Warehouse Code
  • Warehouse Name
  • Warehouse Type
  • Manager
  • Contact Details
  • Address
Used in: Stock Production Employee Assignment

Raw Material

Masters → Raw Material

What is it?

Raw materials are the ingredients used during production.

Examples

  • Clove
  • Cardamom
  • Cinnamon
  • Pepper
Used in: Stock Receive Production

Product

Masters → Product
Important

Product Master is created by Admin before production. Production does not create a new Product Master.

Admin needs to create

  • Product Name
  • Product Code
  • Brand
  • Category
  • HSN
  • GST
  • Product Variants
  • SKU Code
  • Pack Size
  • MRP
Used in: Production Finished Goods Sales
03

Inventory Management

Inventory records actual materials received and available stock.

Stock Receive

Admin Inventory → Stock Receive

When to use?

When raw material is physically received from a supplier, Admin creates a Stock Receive entry.

Example

Supplier 500 KG Clove Hyderabad Warehouse
Creates: Raw Material Stock

Raw Material Stock

Admin Inventory → Raw Material Stock

Purpose

Shows the current available raw material stock in warehouses.

Example

Received: 500 KG

Used in Production: 50 KG

Available: 450 KG

Finished Goods Stock

Admin Inventory → Finished Goods Stock

Purpose

Shows finished products produced by warehouses and currently available for further distribution or sales.

Created from: Production Entry
04

Production Management

Admin gives production instructions and monitors warehouse production.

Create Production Instruction

Production Management → Create Production Instruction

Purpose

Admin tells a particular warehouse what product needs to be produced and in what quantity.

Example

Warehouse Hyderabad WH
Product Clove 10 GM
Target 200 Packs
Admin Production Instruction Warehouse

Production Monitoring

Production Management → Production Monitoring

Purpose

Admin can monitor production instructions and their current status.

Pending Accepted In Progress Completed
05

Warehouse Management

Warehouse handles production execution and physical stock.

Warehouse Process

Admin Instruction → Warehouse Accept → Production Entry → Finished Goods

Assigned Production

Warehouse Manager sees production instructions assigned by Admin.

Accept Production

Warehouse accepts the production instruction.

Production Entry

Warehouse enters actual production quantity and details.

Finished Goods

Completed production becomes finished goods stock.

07

Distributor Management

Distributor receives finished goods and manages assigned employees.

Distributor

Distributor Management → Distributors

Purpose

Admin creates distributors who will handle stock and sales for their assigned area.

Stock Transfer

Distributor Management → Stock Transfer
Warehouse Stock Transfer Distributor

Finished goods can be transferred from warehouse stock to distributor stock.

Distributor Stock

Distributor Management → Distributor Stock

Purpose

Admin can monitor stock available with each distributor.
